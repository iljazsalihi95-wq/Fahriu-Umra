# Fahriu Umra — rikonstruktimi i projektit ekzistues

Ky repository është burimi i ri i projektit ekzistues Fahriu Travel / Umra në AppCreator24 dhe Netlify. **Nuk është një aplikacion demonstrues.**

## Parimet
- Ruaj ikonën dhe identitetin origjinal; mos përdor ikona zëvendësuese.
- Importo HTML/CSS/JS/PWA dhe Apps Script ekzistues para ndryshimeve në UI.
- Mos publiko çelësa API, të dhëna personale ose kredenciale në GitHub.
- Mos shpall një funksion si të testuar pa provë funksionale.
- Integrimi Cloudflare Worker kërkon kontroll të URL-së, routes, secrets, CORS dhe ruajtjes së të dhënave.

## Modulët e planifikuar
Ballina; ofertat dhe regjistrimet; grupet; njoftimet; Meka; Medina; Taif; vizitat; udhëzuesi i Umres; dua dhe dhikër; Nusuk; bileta; LIVE; momente; ekipi; administrimi.

## Udhëzuesi i Umres
Burimi fillestar: *Rituali i Umres*, Muhammed ibën Salih el-Uthejmin, përkthim Alban Malaj (© Selefi.org). Burimi nuk duhet ribotuar i plotë pa leje. Udhëzuesi i ri duhet të jetë shpjegim origjinal me referenca, duke dalluar mendimet e medhhebeve kur është e nevojshme.

Rendi bazë: përgatitja dhe ihrami → telbija → tauafi (7 rrotullime) → dy rekate → sa'ji (7 ecje) → shkurtimi/rruajtja e flokëve.

## Status
Repository i sapokrijuar; skedarët origjinalë të aplikacionit dhe ikona ende nuk janë importuar. Nuk është verifikuar deploy-i në Netlify apo Cloudflare.
